# BarberShop – Landingpage

Eine Landingpage für einen fiktiven Barbershop in der Bremer Altstadt. Das ist ein Lernprojekt, bei dem ich ein Design ohne Framework mit HTML, CSS und Vanilla JavaScript umgesetzt habe.

**Live-Demo:** _(Link zu GitHub Pages hier eintragen)_

## Sections

- **Hero:** Formular zur Terminanfrage über einem Hintergrundbild mit Verlauf
- **Über uns:** Bild-Slider mit Zähler, Kundenbewertungen und Preisliste
- **Standort:** Karte mit Link zu Google Maps, Adresse und Öffnungszeiten
- **Experten:** Team-Karten in einem automatisch umbrechenden Grid
- **Footer:** Kontakt, Menüs und ein Button, der nach oben scrollt

## Technik

- HTML5 mit semantischen Elementen (`header`, `main`, `section`, `article`, `footer`, `address`)
- CSS mit Custom Properties (Farben und Fonts), Flexbox und Grid
- JavaScript für Smooth Scroll, die Header-Farbe beim Scrollen, den Bild-Slider und die Review-Card
- Bilder als WebP, mit Lazy Loading

## Lokal starten

Repo klonen und `index.html` im Browser öffnen, zum Beispiel mit der VS-Code-Erweiterung „Live Server“.

## Hinweis

Der Shop, die Namen und die Kontaktdaten sind erfunden. Die Seite ist ein reines Demo-Projekt.
